# BillZ Releases

Official release repository for **BillZ** — Modern Retail POS with Multi-Counter LAN Billing.

## Download

Go to the [**Releases**](https://github.com/UtkarshKarale/billz-release/releases) page to download the latest version.

### Available Formats
| Platform | Format |
|----------|--------|
| Windows  | `.exe` (NSIS Installer) |
| Linux    | `.AppImage`, `.deb`, `.snap` |

## How Updates Work

The BillZ app automatically checks this repository for new releases on startup. When a new version is available, you'll see an update notification inside the app.

## Release Notes Format

Each release includes:
- **Tag**: Version number (e.g., `v1.0.6`)
- **Release Notes**: What's new in this version
- **Assets**: Platform-specific installers

---

> This repository contains **only release artifacts** (installers and binaries). No source code is stored here.
